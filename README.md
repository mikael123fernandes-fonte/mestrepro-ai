
# ⚡ MestrePro AI

Aplicativo inteligente para profissionais de manutenção residencial e predial.

## Objetivo

O MestrePro AI é uma plataforma criada para facilitar o dia a dia de eletricistas, encanadores, pintores e profissionais de manutenção, permitindo criar orçamentos, gerenciar clientes e controlar serviços em um único lugar.

## Recursos

- 📋 Orçamentos Inteligentes
- 👥 Cadastro de Clientes
- 📅 Agenda de Serviços
- 📦 Controle de Materiais
- 📄 Geração de PDF
- 🤖 Assistente com Inteligência Artificial
- 💰 Controle Financeiro
- 📷 Análise de imagens (em desenvolvimento)

## Tecnologias

- Flutter
- Firebase
- GitHub
- OpenAI
